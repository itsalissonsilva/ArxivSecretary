# Privacy Policy

Last updated: April 21, 2026

## Overview

ArXivSecretary is a Windows desktop application that helps users track authors, topics, and institutions on arXiv.

ArXivSecretary does not create user accounts and does not collect personal data for transmission to the developer.

## Data Stored Locally

ArXivSecretary stores information locally on the user's device, including:

- tracked authors, topics, and institutions
- application preferences
- alert and scheduling settings
- API keys entered by the user for OpenAI or Anthropic
- SMTP credentials entered by the user for email notifications
- summaries and data retrieved from arXiv

This information is stored locally on the user's computer and is not sent to the developer.

## Third-Party Services

Depending on how the user chooses to use the application, ArXivSecretary may connect directly to third-party services, including:

- arXiv, to retrieve papers and metadata
- OpenAI or Anthropic, when the user requests AI-generated summaries
- an SMTP email server configured by the user, when the user enables email notifications

When these features are used, the data necessary to perform the requested function may be transmitted directly to the relevant third-party service.

## Generative AI

If the user configures an OpenAI or Anthropic API key, the application may send paper titles, abstracts, and related metadata to the selected provider in order to generate summaries.

## Data Sharing

The developer does not receive, sell, or share user data. Any data transmission occurs only between the application and the third-party services selected by the user.

## Security

Data is stored locally on the user's device. Users are responsible for protecting access to their device and any credentials they enter into the application.

## Contact

For privacy or support questions, users may contact the developer using the support contact information provided in the product listing or repository.
